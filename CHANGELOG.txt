[2026-05-29] Shake fix + Play Again
-------------------------------------
CHANGED  components/GameMap.tsx — replaced rAF + jumpTo() animation with a
         single easeTo() call using a custom Catmull-Rom easing function.
         Root cause of shaking: jumpTo() called 60×/s from an external rAF
         loop conflicts with Mapbox's own WebGL render cycle, causing
         sub-pixel jitter. Using easeTo() lets Mapbox drive all interpolation
         internally with no external camera writes → shake eliminated.
ADDED    zoomEasing(t) — inverts catmullRomZoom to [0,1] progress so it can
         be passed directly as the easeTo easing parameter
REMOVED  animRafRef, requestAnimationFrame loop, drift constants
         (MAX_DRIFT_LNG / MAX_DRIFT_LAT / DRIFT_START) — drift removed since
         it required jumpTo() and is incompatible with the single-easeTo model
ADDED    Feature: Play Again
CHANGED  app/page.tsx — now 'use client'; tracks round state; passes
         key={round} to GameWrapper (forces full React remount on new round →
         fresh randomLandPoint, fresh map, all state reset) and passes
         onPlayAgain callback
CHANGED  components/GameWrapper.tsx — accepts onPlayAgain?: () => void prop,
         threads it through to ResultOverlay
CHANGED  components/ResultOverlay.tsx — accepts onPlayAgain?: () => void prop;
         renders "Play again" button at the bottom of the result card


[2026-05-29] Seamless zoom animation
--------------------------------------
CHANGED  components/GameMap.tsx — replaced 4× chained easeTo with a single
         requestAnimationFrame loop driven by a Catmull-Rom spline through
         ZOOMS [16, 14, 11, 6, 3.5] over TOTAL_MS (20 000 ms).
         Catmull-Rom gives C¹ continuity — non-zero velocity at every
         interior waypoint — so the camera flows through all four zoom levels
         without decelerating to a stop between phases.
REMOVED  PHASE_MS constant (no longer needed)
ADDED    catmullRomZoom(t) helper — Catmull-Rom spline with clamped phantom
         endpoints so the curve hits exactly ZOOMS[0] and ZOOMS[last]
CHANGED  frozen effect now calls cancelAnimationFrame(animRafRef) before
         easeTo so the rAF loop doesn't fight the zoom-out animation
ADDED    animRafRef to store the active rAF ID for cancellation on unmount
         or freeze

[2026-05-29] Wall-clock timer + multiplicative scoring
-------------------------------------------------------
CHANGED  lib/haversine.ts — calcScore() signature and formula
         OLD: additive   distScore(0–4 000) + speedBonus(0–2 000), max 6 000
         NEW: multiplier accuracy(0–3 000) × multiplier(1.0–2.0), max 6 000
         Prevents gaming the system: an instant random guess no longer earns
         a guaranteed 2 000-pt speed bonus regardless of accuracy.
CHANGED  components/GameWrapper.tsx
         - Replaced integer timeLeftAtResult + timeLeftRef with float timeTakenSec
           and gameStartTimeRef (Date.now()-based wall-clock)

           time to 2 decimal places via parseFloat(elapsed.toFixed(2))
         - On time expiry: timeTakenSec set to GAME_DURATION (multiplier = 1.0)
CHANGED  components/ResultOverlay.tsx
